# Valstrax Rail

Valstrax Rail es una aplicación web desarrollada como Trabajo Final de Grado (TFG) para la gestión de reservas de transporte ferroviario de mercancías.

La plataforma permite a los usuarios consultar viajes disponibles, reservar espacio en vagones, realizar el seguimiento de sus pedidos y efectuar pagos en modo de prueba mediante Stripe. Además, incluye un panel de administración para gestionar trenes, vagones, estaciones, viajes, usuarios y pedidos.

## Tecnologías utilizadas

- **Python**
- **Flask**
- **MySQL**
- **Tailwind CSS**
- **Flask-Login**
- **Stripe Checkout**
- **JavaScript**
- **DataTables**

## Funcionalidades principales

- Registro e inicio de sesión de usuarios
- Sistema de roles (usuario / administrador)
- Gestión de trenes, vagones, estaciones y viajes
- Reserva de espacio en viajes disponibles
- Seguimiento de pedidos mediante código y correo electrónico
- Envío de correos con información de seguimiento
- Panel de administración con tablas y métricas
- Integración de pagos en modo de prueba con Stripe
- Páginas de error personalizadas
